# Card: H-COST, rendering-dependent perceptual cost of upstream errors

- **Title (working):** When committing hurts: the perceptual cost of upstream errors depends on how a generator renders them.
- **Problem:** generators commit to uncertain upstream inferences (who speaks). Does the cost of being wrong depend on how strongly the output commits?
- **Motivation:** multi-voice audiobooks assume correct attribution, but real attribution is wrong 13-36% of the time even on classics (H-CAL), and more distinct voices mask fewer errors (H-GATE).
- **Prior art / gap:** Selective Abstraction App. I (subjective risk open); MultiActor MOS-S (no manipulated errors); Deep Dubbing (assumes accuracy). See `PRIOR_ART_MATRIX.md` T1.
- **Hypothesis:** a rendering × accuracy interaction exists in comprehension and preference, larger with a distinctive cast and varying by error type.
- **Method:** injected errors by measured type, across distinctiveness-controlled casts and rendering rungs; a loss table from listeners; the Bayes rung per line.
- **Data:** PDNC passages (public-domain text, human gold).
- **Experiments:** listening pilot (n ≈ 24), then a powered study (n ≈ 50).
- **Baselines:** always full cast; always narrator; the product's 0.7 unconfirmed-voice gate; oracle.
- **Ablations:** cast distinctiveness; error type; spoken tags vs tags removed.
- **Human study:** `listening_study.html` (Latin square, probes, noticing, enjoyment).
- **Statistics:** cluster bootstrap by listener on the difference-in-differences; power by simulation.
- **Failure cases so far:**
  - same-gender errors under-realised;
  - duration confound between narrator and cast renders.
- **Limitations:**
  - embedding distance is not perception;
  - EARS is non-commercial;
  - English classics only.
- **Generalization:** dubbing, multi-speaker captioning, comics, any agent rendering uncertain beliefs vividly.
- **Practical impact:** the casting policy and review-queue ordering in the product.
- **Theoretical insight:** the error cost depends on the output form, which is the missing piece in selective-prediction theory for perceptual outputs.
- **Patent:** none at present.
- **Reproducibility:** `python -m echotales.research run error_cost_stimuli [--param synthesize=true]`.

# Pre-registration PD CONFIRM: one frozen confirmatory study of name-keyed memory leakage, with a mitigation and a harm task (version 1)

Status: **DRAFT for owner approval at CP-K; becomes FROZEN when the owner says continue.** Its SHA-256 and those of every file it names are in `MANIFEST_PD_CONFIRM.json`. After freezing, any change is a new version; nothing here is edited. Branch `chimera/system-adapters`, drafted 2026-10-16.

**CP-K revision log (2026-10-16, before freezing; owner feedback).** (1) No OpenAI model is used anywhere in this study (no `gpt-5.6-luna`, no `gpt-4o-mini`; the miner, auditor and judge are open models). (2) Open-weight models run on RunPod GPUs; one closed frontier model, **Claude Sonnet 5.5, runs through the owner's Claude subscription** with the headless CLI (scope reduced, section 5). (3) The owner delegated the design size: **150 events (30 dev, 120 test), 7 items per event** (4 pre-reveal, 1 post-reveal, 2 plain controls). (4) E2 cannot use the serials RI and LOTM (copyrighted and published before every model's cutoff; see section 9) and the owner holds no licence for any post-cutoff text, so E2 is **LLM-authored 2026 fiction, unseen by construction** (section 9). These replace the OpenAI-based cost model of the first draft; the hypotheses H1 to H6 are unchanged.

**Status of earlier work.** PD v1 to v7, the cue-preserving test, the dose-response and the label audit (report v1.6 and later) are **exploratory**. They were run in sequence, rules changed between versions, and several analyses were post hoc. This study is **confirmatory**: every analysis, metric, exclusion rule and decision rule is written here before any model sees a test item. One run on the test split, no re-analysis versions afterwards; any extra analysis is labelled exploratory.

**Label provenance (every number).** The oracle is **text-derived** (the book's own explicit reveal sentence located by exact search, verified deterministically and audited by an independent model; see `PD_CONFIRM_event_mining_rules_v1.md`). Events are model-selected; no human label exists or is planned for this study (owner decision); no number may be described as human-verified. The text-derived oracle fixes what the *book states*, not what a reader infers earlier from hints.

## 1. Research questions and the reader-faithfulness frame
Parametric memory is one way a model's output at reader position c can depend on chapters after c. The study measures it at scale and tests a mitigation. Its questions: **E1** is name-keyed memory leakage present across models and books (scale)? **E2** does it vanish on text the models cannot have seen? **E3** how does it vary across at least three model families and with book fame? **E4** does consistent pseudonymisation with back-mapping cut premature naming without losing utility? **E5** does the leakage produce spoilers in a realistic reader task (recap and character profile), and does the mitigation cut them?

## 3. Data
- **E1 events:** 150 events (acceptable 120 to 200 if the mining yields fewer or more) from at least 60 books, mined by the fixed rules, drawn stratified by fame band, at most 5 per book. **Split by book:** 20% dev, 80% test (rule in the mining file). **Primary set:** events the independent audit labels EXPLICIT; **secondary set:** all verified events.
- **Items per event:** up to 4 pre-reveal, up to 1 post-reveal, 2 plain controls (one non-identity name, two mentions; mining rules, section 10).
- **E2 unseen text:** 40 LLM-authored 2026 stories with an explicit alias-to-identity reveal (section 9). Same verifier, same arms. Owner-supplied real post-cutoff text, if it ever arrives, is an additional exploratory set.
- **G2b synthetic control:** the 62 synthetic unseen-text items of PD v3 (identical prompts), for each model.

## 4. Arms (letter-format answers, prompts reused unchanged)
A original names; B one consistent letter cipher on all proper nouns (T4 v5 cipher, seed 20261015); **B3** cue-preserving natural pseudonyms for the event's cast and alias name tokens with every other proper noun ciphered (PD v5 construction, seed 20261018 plus Gutenberg id); **B2** (second cipher, seed 20261016) **on plain controls only**, to compute the cipher-agreement gate G2a. Per event: the alias-only closed book (C_orig, C_ren) and the title-assisted probe M2 (three arms, `PD_prompts_v4.json`), reported as covariates.
**E4 arms (open-name answers, `PD_confirm_prompts_v1.json`):** **O** original names; **P1** original names plus the plain instruction "use only the text provided, not outside knowledge"; **P2** cue-preserving pseudonymisation with back-mapping of the answer; **P3** cipher pseudonymisation with back-mapping; **P4** (reported only, no calls) P3's raw answers scored without mapping back. Pseudonym maps are built from the oracle cast list (an upper bound for a detector-based pipeline; a regex-detector variant is exploratory).
**E5 conditions:** O, P1, P2 as above, on two tasks per test event: a "story so far" recap (at most 200 words) and a profile of the aliased character (at most 100 words), given the **last 24,000 characters of the prefix ending at the event's cutoff**.

## 6. Hypotheses and decision rules (confirmatory family)
Notation. For model *m* and test event *e*: `g(e,m)` = mean over its pre-reveal items of `1[answer = identity letter | A] - 1[answer = identity letter | B]`; INVALID counts as not premature. `y_m` is the mean of `g(e,m)` over primary-set test events; its variance `v_m` is the event-cluster bootstrap variance (10,000 resamples of events, seed 20261101).
- **H1 (leakage exists across models).** DerSimonian-Laird random-effects pooled estimate of `y_m` over the models, with a Hartung-Knapp 95% interval (t with k-1 degrees of freedom): pooled estimate at least **+10 points** with lower bound above 0, **and** at least 3 of the 4 core models individually positive with Holm-adjusted one-sided event sign test p below 0.05.
- **H2 (not cue loss).** Same pooled structure for `A - B3`: pooled `A - B3` at least +10 points with lower bound above 0, **and** the pooled recovered fraction `R = (rate B3 - rate B) / (rate A - rate B)`, event-cluster 95% interval, has its **upper bound below 2/3** and point estimate below 1/3.
- **H3 (fame dose-response).** Spearman correlation between `F_wiki` of the book and the event gap `g(e) = mean over models of g(e,m)`; one-sided permutation p below 0.05 with 20,000 shuffles **of the fame values across books** (not events), correlation at least 0.20.
- **H4 (unseen text; run only if at least 40 verified E2 stories exist).** For each model except Claude Sonnet 5.5 (E1 and M2 only): gap on the E2 stories has an event-cluster 95% upper bound below +10 points, and the E1 gap minus the E2 gap has a 95% lower bound above 0. H4 is a test of *estimated* equivalence-ish behaviour, not of equivalence: with 40 events the 95% half-width is about 9.2 points (power analysis, section 8), so a gap below about +9 cannot be excluded.
- **H5 (mitigation counts).** For the pooled data and each model, with P2 as the mitigation: (a) relative reduction in premature naming, `1 - rate(P2)/rate(O)`, at least 50% with event-cluster lower bound above 0; (b) **utility inside the margin**: correct naming on post-reveal items and accuracy on plain controls under P2 are each at most **5 percentage points** below O, tested as non-inferiority (one-sided 95% lower bound above -5 points); (c) P2 beats the plain-instruction baseline P1 on premature reduction by at least 5 points, event-cluster lower bound above 0. A mitigation counts only if (a), (b) and (c) all hold; P3 is reported as a second pseudonymisation variant, not added to the family.
- **H6 (harm task).** Spoiler = in a recap or profile, a capitalised identity-name token of at least 3 letters that does **not** occur in the 24,000-character input appears in the output after mapping pseudonyms back (events whose identity tokens all occur in the input are excluded from E5 and counted). (a) Pooled spoiler rate under O at least 5% with lower bound above 0; (b) P2 reduces the pooled spoiler rate by at least 50% relative, lower bound above 0; (c) **faithfulness**: on a 25% random sample of E5 outputs judged by an open model of a different family from the output's model (`Qwen2.5-72B-Instruct-AWQ`, or `Llama-3.3-70B` for Qwen outputs; prompt `faithfulness_judge`; the judge is also an evaluated model, a stated self-preference risk), the unsupported-claim rate under P2 is at most 5 points above O (non-inferiority, upper bound below +5 points).
- **Multiplicity.** The pooled tests H1, H2, H3, H5, H6 are corrected with the Holm procedure at family-wise 0.05; H4 is reported alongside (its availability depends on the data). Per-model analyses within a hypothesis are corrected across the models by Holm. Everything not listed is exploratory and labelled so.

## 7. Estimation and inference (fixed)
Event is the resampling unit throughout (10,000 resamples, seed 20261101); items within an event are never treated as independent. Per-model results are reported for every model whatever their size (no validity gate in the primary analysis). **Secondary:** the memory-free-gate pool (models with B-versus-B2 agreement on controls at least 90% and synthetic A-versus-B agreement at least 80%), the secondary event set, events dropping the audit-IMPLIED, and the model-specific recognition score. A model cell with more than 10% INVALID answers is flagged and excluded from the pooled estimate of that hypothesis (reported). Events with fewer than 3 usable pre-reveal items in a model's cells are excluded for that model.

## 8. Power analysis (computed before any model call; `confirm_design_numbers.py`, `confirm_design_numbers.json`)
From the 38 existing events the event-level SD of the gap is 0.295 for Luna (0.22 to 0.32 for the local models). With that SD and **120 test events** a one-sample test has **80% power to detect a gap of 7.5 points at 0.05 and 9.0 points at the Holm-adjusted level 0.0125** (the first draft's 160-event design: 6.5 and 7.8). H1's +10 threshold therefore sits only just above the minimum detectable gap; if the open models leak less than the reference model did in exploratory work, H1 may fail for lack of power and will be reported as such. A Spearman correlation of 0.25 needs about 124 events and 0.20 about 194, so H3 (threshold 0.20, 150 events) is underpowered for small correlations. Non-inferiority with a 5-point margin and a paired event-level SD of 0.15 has power 0.97 at 120 events. **E2:** equivalence within +-5 points would need about 300 events and within +-8 points about 117; with 30 events the 95% half-width is 10.6 points and with 40 events 9.2 points, which is why H4 is stated as an upper-bound test.

## 9. E2: unseen text (revised at CP-K)
**Why not RI or LOTM.** *Reverend Insanity* (serialised from 2012) and *Lord of the Mysteries* (English web translation since 2021, a print licence announced December 2024) are copyrighted works whose English editions are commercially licensed (Qidian International and Yen Press respectively; web search results, tag LEAD, no terms text found); the owner holds no licence; and both were published before every model's training cutoff, so they would be **seen** text, not an unseen control. Their sites' terms of service could not be retrieved (Royal Road HTTP 403, Archive of Our Own HTTP 525; `INACCESSIBLE`). The public web-novel datasets found are restricted or are not English serial text (GuoFeng Webnovel: copyright held by Tencent AI Lab and China Literature, registration required, redistribution prohibited; Qidian-Webnovel Corpus: reader comments, restricted; GenWebNovel: Chinese NER; WebNovelBench: a benchmark). No scraping and no access-control workaround is used. RI and LOTM stay local, as before, for system-internal audits only.
**Design.** Forty stories of 3,000 to 5,000 words, written in 2026 by an open model of a family that is **not evaluated** (`mistralai/Mistral-Small-3.2-24B-Instruct-2506`, seeded), each built from a fixed template prompt (a person introduced only by an alias or a description, a cast of 7 to 9 invented names, an explicit sentence several chapters later naming the person). The same deterministic verifier keeps only stories whose reveal sentence is found exactly once and that satisfy the mining rules (the generator's own claims are not trusted). The text cannot be in any model's training data because it did not exist. It is **LLM-authored, not human-written fiction, and says nothing about human web serials**; it measures whether the gap appears on long natural-language narrative no model has seen.
**If real post-cutoff text is supplied** by the owner (their own writing, or text with a licence that allows this use) it is analysed as an additional exploratory set.

## 10. Exclusions, deviations, safety
No post-hoc exclusion. A deviation (a failed model endpoint, a changed provider, a cell with persistent API errors) is logged in `PD_CONFIRM_deviations.md` with its date before the affected analysis is read. No novel text is written to any repository file; public-domain texts are re-downloaded to the git-ignored `data/raw/`; supplied E2 text, if any, stays outside the repository. No API key or token is read or printed (RunPod and vLLM tokens live in `.env`, read only inside a subshell). No OpenAI model is used. GPU rental is the owner's: the owner creates the RunPod pod from the exact specification in the CP-K audit (or, with a RunPod API key placed in `.env`, approves a stated hour cap before the agent rents anything); every GPU session is logged in `SPEND_LEDGER.md` with hours and cost; the agent never rents anything on its own authority. **Shrink rule fixed now:** if the calibration run projects a cost above the owner's budget at 2x, the design shrinks, with no other change, to 120 events, 48 E5 events and 40 E2 stories.

## 11. Limits stated before the run
Model-selected events with no human check; the mining restricts events to reveals stated in a sentence matching the cue list; the miner (Llama) and the auditor (Qwen) are open language models that are also evaluated; Claude Sonnet 5.5 is run without control of temperature or seed and with reduced scope; E2 text is LLM-authored (a different family from every evaluated model except possibly style overlap); fame bands rest on Wikipedia coverage; the pseudonym arm and the mitigation use the oracle cast list (an upper bound); the 70B-class models are served 4-bit (AWQ), which may change behaviour relative to full precision; temperature-0 API outputs are not guaranteed identical across runs; public-domain pre-1928 English fiction only; E2 power is limited; the spoiler oracle is a string rule that misses paraphrased disclosure and flags coincidental token overlap, and it is validated only on a sample.

# ner_romanized: span-level NER gold for romanized and unfamiliar names

Evaluates mention *detection* only (which character spans are names), not identity resolution. English prose only:
no native CJK text, no translation. Harness: `echotales.pipeline.eval.ner_spans`; runner: `scripts/eval/ner_bakeoff.py`.

Files: `synthetic_dev.jsonl`, `synthetic_test.jsonl` (generated by `scripts/eval/build_ner_romanized_gold.py` from
marker-annotated passages in `scripts/eval/ner_gold_passages/`; do not hand-edit the JSONL). Public-domain excerpts
are `public_domain_dev.jsonl` / `public_domain_test.jsonl` (`"source": "public_domain"`, plus `work` and `gutenberg_id`);
the loader reads every `*.jsonl`.

Record: `{doc_id, source: synthetic|public_domain, background: zh|ko|ja|in|eu|invented|mixed, split: dev|test, text,
spans: [{start, end, surface, label, category, generic_role?}]}`. Offsets are Python character offsets, end exclusive, and
`text[start:end] == surface` is validated. Dev is for tuning thresholds; test is run once.

Labels: `person`, `title_epithet`, `location`, `organization`, `item`.
Categories (one per span): `ordinary`, `unfamiliar_fantasy`, `invented`, `title` (name carrying a title or
honorific, "Elder Mo"), `alias_epithet` (a different expression for an already-named entity), `word_like` (name
that is an ordinary English word: Rain, Hope, Will, Grace, Joy, Hunter, Bai), `sentence_initial` (name at a
sentence start), `shared_title` (one title held by different people in the same text, "the clan head").

## Annotation rules

- Annotate proper names and *named* titles/epithets that refer to a specific entity ("the Venerable", "Heavenly
  Demon"). A title used alone for one specific person ("the clan head", "the Jarl") is `title_epithet`.
- Do not annotate pronouns, generic descriptors ("the old man", "a disciple", "the envoy"), or common nouns.
- Kinship and relational address terms used alone (Maa, Amma, Beti, Thambi, Uncle) are relational references, not names: annotated as `title_epithet` with `generic_role` forced, so they are excluded from name metrics like other generic roles.
- Attached honorifics and titles are inside the span ("Dokja-ssi", "Gojo-sensei", "Mr. Darcy", "Lady Hartley"); see
  the boundary policy below.
- Strip possessive 's from the span. Each occurrence is its own span; spans never overlap.
- Named animals count as `person` (the set has a terrier called Hunter). Named artefacts, techniques, and
  creatures-as-objects are `item`. A building or ship named like a place is `location`.
- Deliberate negatives are left unannotated so precision is measurable: capitalised sentence starts ("Hope you
  slept", "Rain pattered"), generic "Heaven", bare "Sect", wing or school words, chapter references.

## Boundary policy

Applied to every span in the set (changes are logged in `CHANGELOG.md` by rule letter):

- **(a)** A capitalised title, rank or honorific word immediately preceding a name is part of the span ("Captain
  Yoo", "Sentry Dovrin", "Elder Moon", "Mr. Darcy", "Lady Murasaki"). A lower-case descriptor ("old Srutasravas")
  and a class noun ("the Brahmana Kalaghata") are not titles in this sense and stay outside.
- **(b)** An attached hyphenated honorific is part of the span ("Dokja-ssi"). A spaced suffix ("Tae-sik sunbae") is
  not covered; the span stays the bare name.
- **(c)** A following "the X" epithet joined to the name without a comma is part of the span ("Sigrid the Younger").
  An epithet set off by a comma is a separate appositive.
- **(d)** "of <Place>" after a title is not part of the person span unless it is a fixed title: "King Wên of
  Chʻu" is "King Wên" plus "Chʻu" as a separate location.
- **(e)** Every named place, organisation, item and person occurrence is annotated, real-world places included
  ("Kerala", "Manchuria").
- **(f)** The `generic_role` rule is unchanged (see Scoring conventions).

## Scoring conventions

**Headline: `boundary`** (convention-tolerant), with `exact` and `overlap` reported alongside. Boundary matches two
overlapping spans whose surfaces are equal after trimming a leading article and attached honorifics (the project's own
`ingest.normalize.strip_honorifics`, case-folded). Reason: on gemma2:9b dev most exact-mode errors (99 FP / 115 missed)
were convention mismatches ("the Emperor" vs "Emperor", "Dokja" vs "Dokja-ssi"), not detection failures. Not covered
because `strip_honorifics` does not know them: spaced suffixes ("Tae-sik sunbae") and "Mr. and Mrs. Collins" vs
"Mrs. Collins".

**`generic_role`**: a span-level boolean written by the builder on `title_epithet` spans whose surface (minus a leading
article) is all lower-case ("the dean", "guild master", "village chief"). EchoTales keeps generic descriptors out of
the graph (non-negotiable 4), so by default these gold spans are excluded from the name metrics (not a miss if
skipped, and a prediction matching one is not a false positive) and reported as `generic_role` recall. Capitalised
titles ("the Emperor", "Heavenly Demon") are ordinary gold. `--include-generic` (`include_generic=True`) scores them as
names. Flagged: 19 synthetic dev, 31 synthetic test, 0 public-domain dev, 5 public-domain test.

Nested predictions (a short surface strictly inside a longer predicted span, e.g. "Bai" in "Bai Ningbing") are dropped
in `normalize_predictions`, matching the `QwenNerDetector._locate` fix, so result files written before that fix rescore
fairly.

Greedy 1:1 matching, boundary, exact and overlap, span-only and label-aware. `person` and `title_epithet` are one compatible
group (a detector predicting `character` for "the clan head" is correct). Passages are 60-90 words, shorter than a
chapter window: this measures detection quality, not long-context behaviour.

Status: **silver: two independent model passes plus adjudication, not owner-checked.** Raw pass A vs pass B span F1
0.886 (exact match, 331 vs 290 spans); disagreements and resolutions are in `public_domain_adjudication.md`. The
bare-title rule (a sole-referent title such as "the Emperor" is `title_epithet`) is the biggest judgement call.

`ner_bakeoff.py --source public_domain|synthetic` scores one source alone.

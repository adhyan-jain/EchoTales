Check what a reader knows at a cut

Each item is a character in a novel and a few passages that mention them, taken only from the part of the book up to a cut point. You decide what those passages let a reader conclude about the character's gender, then see what a system served for that character at that cut and say whether the passages back it up. You do not need to have read the book, and you should not read ahead. It takes about 4 minutes per item.

  1. Pick your name below. You only see the items assigned to you.
  2. Read the guidelines once (2 minutes).
  3. For each item, answer the first part, press Show system output, then answer the second part. Once shown, the first part is locked.
  4. When the counter shows all items done, press Export my labels and send the downloaded file to Adhyan.

Judge only the text shown. Do not look anything up, and do not discuss items with the other annotators until everyone has exported. Some items repeat on purpose, so answer each one on its own. If you switch device, export first and use Import on the new one.

Guidelines

You are checking what the book has shown a reader by the cut, not what is true of the whole book. Passages stop at the cut. Judge only the text shown, and do not use what you remember of the book (Q0 records whether you do).

Q0. Do you know this book's plot?

Answer before reading. Yes if you have read the book or an adaptation, or already know this character.

Part 1. Before seeing any system output

Q1. From the passages alone, is the character male, female, or not determined? Choose male or female only if the text signals it: pronouns for this character, a gendered title or kinship term used of them (Mr, Madame, "the young lady", "her father"), or an unambiguous description. A name that sounds male or female, or a stereotype, is not a signal. Several characters may appear in a passage, so check that the cue refers to this character.

Q2. How sure are you? Clear: explicit and unambiguous cues. Suspect: hints, but not settled. None: no usable cue.

Part 2. After pressing Show system output

Q3. The system served a value for this character at the cut. Is it supported by the passages, unsupported (the passages say nothing that settles it), or contradicted (the passages point the other way)?

If the system served no value, Q3 asks instead whether the passages did settle one (so a value could have been served) or did not.

Q4. Would a careful first-time reader of these passages plausibly hold the served value? Not asked when no value was served.

Needs broader context

Tick this if your answers depend on events that are not in the passages shown (for example you suspect a cue exists elsewhere before the cut). Do not tick it just because you are unsure; use Q2 for that.

Notes

Optional. Write anything odd (garbled text, two characters mixed up, a passage that is not about this character).
